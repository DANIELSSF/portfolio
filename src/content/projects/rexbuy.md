Desarrollo de e-commerce fullstack con autenticación, roles de usuario e integración de PayPal. Gestión completa de productos, usuarios y pedidos con funciones como carrito de compras, reseñas de productos, favoritos, búsqueda de productos e interfaz intuitiva. Incluye un chatbot utilizando la API de OpenAI.
